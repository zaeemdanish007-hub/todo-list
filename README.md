# 📝 To-Do List

A simple and responsive To-Do List web application built with **HTML, CSS, and JavaScript**.

The project allows users to easily manage their daily tasks with a clean and modern interface.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks at once
- ⌨️ Add tasks using the **Enter** key
- 🚫 Prevent empty tasks from being added
- 📱 Responsive design for different screen sizes
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, layout, responsiveness, and UI design
- **JavaScript** — DOM manipulation and task functionality
- **Font Awesome** — Task action icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/zaeemdanish007-hub/todo-list
```

### 2. Open the project

Navigate into the project folder:

```bash
cd todo-list
```

### 3. Run the application

Open `index.html` in your web browser.

No additional dependencies or installation are required.
